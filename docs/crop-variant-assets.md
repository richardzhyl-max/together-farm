# 作物变异素材生成提示词

素材输出目录：

`public/assets/game/crops/variants/{cropKey}/golden.webp`

`public/assets/game/crops/variants/{cropKey}/rainbow.webp`

要求：512x512、透明背景、与原普通作物保持同轮廓和可读性。
